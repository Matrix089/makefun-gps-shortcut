A tiny Python program that writes the GPS's excuse for sending the driver down the wrong road, one line, to /output/entry.txt for make.fun's The GPS Swears It Was a Shortcut bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
